Fallo de login GS64 por error 'invalid_request' de Auth0, la UI de Pepper no se renderizó.

Descripción detallada

El test 'Login > Ingresar y hacer login' intentaba autenticarse en Pepper usando el flujo GS64 a través de Auth0. El fallo ocurrió en un comando utilitario que esperaba la correcta renderización de la UI de Pepper, pero en su lugar se mostró una página de error de Auth0. La evidencia del DOM al momento del fallo muestra un error 'Oops!, something went wrong' con el detalle 'invalid_request', impidiendo que la aplicación de Pepper cargara.

Posibles causas

ALTA
Error 'invalid_request' de Auth0
El DOM al momento del fallo muestra explícitamente una página de error de Auth0 con el mensaje 'invalid_request', indicando un problema con la solicitud de autenticación o la sesión.
MEDIA
Configuración incorrecta de Auth0 o Cypress cy.origin/cy.session
El mensaje de Auth0 menciona 'misconfiguration in the system' o 'issue with cookies', lo que podría apuntar a un problema en la configuración del entorno de test o en cómo Cypress maneja las sesiones/cookies con cy.origin.
MEDIA
Credenciales de test inválidas o expiradas
Aunque el error es 'invalid_request', unas credenciales incorrectas o un token expirado podrían llevar a un estado de sesión inválido que Auth0 interprete como una solicitud malformada o no autorizada.

Pasos de Troubleshooting

1 Reproducir el spec fallido con las mismas variables de entorno: TARGET_ENV=production TARGET_CLIENT=br-gs32 MODE=only SPEC=gs32_smoke_all npm run test
2 Verificar los logs de Auth0 usando el 'TRACKING ID: c683e242580e025d8107' para obtener detalles específicos del error 'invalid_request'.
3 Abrir la aplicación manualmente en el ambiente 'production/br-gs32' e intentar el login con las credenciales de test para verificar si el problema es reproducible fuera de Cypress.
4 Revisar la configuración de las variables de entorno PEPPER_USER y PEPPER_PASSWORD para el ambiente 'br-gs32' en 'production'.
5 Si se utiliza cy.session, intentar invalidar la sesión cacheada o deshabilitar cy.session temporalmente para forzar un flujo de login completo.
