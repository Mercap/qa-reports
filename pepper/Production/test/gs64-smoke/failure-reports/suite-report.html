Error de red 403 en API de Calculadora TIR por permisos insuficientes en producción

Descripción detallada

El test 'Herramientas > Calculadora TIR > Descargar el archivo de ejemplo, calcular la TIR y validar el resultado' falló al intentar calcular la TIR. La acción de cálculo provocó una llamada a la API `https://api.brasil.mercap.com.ar/internal-rate-of-return-valuation` que respondió con un status `403 Forbidden`. El test esperaba un `200 OK`, lo que generó un `AssertionError`. La interfaz de usuario también mostró mensajes de error indicando 'No tenés permisos para realizar esta acción' y 'No se pudo calcular la TIR con los parámetros ingresados'.

Posibles causas

ALTA
Permisos insuficientes para el usuario de Cypress
El HAR muestra dos respuestas 403 de la API `/internal-rate-of-return-valuation`, y el DOM al momento del fallo incluye toasts con el mensaje explícito 'No tenés permisos para realizar esta acción' y 'Missing permissions'.
MEDIA
Configuración de roles o políticas de seguridad incorrecta
Si los permisos del usuario son correctos, la configuración del backend para el endpoint `/internal-rate-of-return-valuation` podría estar restringiendo el acceso inesperadamente en el ambiente de producción.
BAJA
Token de sesión GS64 inválido o expirado
Aunque un 403 puede indicar un problema de autenticación/autorización, el mensaje explícito 'Missing permissions' sugiere más un problema de autorización (qué se puede hacer) que de autenticación (quién es el usuario). La duración del test (2607ms) es muy corta para un timeout de sesión.

Pasos de Troubleshooting

1 Verificar los roles y permisos asignados al usuario `cy_smoke@mercapsoftware.com` en el ambiente de producción de Brasil para el módulo de Calculadora TIR.
2 Reproducir el spec fallido localmente con el mismo usuario y ambiente: `TARGET_ENV=production TARGET_CLIENT=br-gs64 MODE=only SPEC=gs64/smoke_herramientas.cy.js npm run test`.
3 Intentar acceder a la Calculadora TIR y realizar la operación manualmente en el ambiente de producción con el usuario de Cypress para confirmar el error de permisos en la UI.
4 Si los permisos parecen correctos, verificar los logs del backend para el endpoint `/internal-rate-of-return-valuation` en el momento del fallo para obtener más detalles sobre el 403.
