Fallo de autorización (403) al calcular TIR en Herramientas

Descripción detallada

El test 'Herramientas > Calculadora TIR > Descargar el archivo de ejemplo, calcular la TIR y validar el resultado' estaba ejecutando. El fallo ocurrió durante el paso de cálculo de la TIR, específicamente al intentar validar la respuesta de la API. El HAR muestra dos requests a 'https://api.brasil.mercap.com.ar/internal-rate-of-return-valuation' que retornaron un status 403 Forbidden. La UI en el momento del fallo mostraba un mensaje de error indicando 'No se pudo calcular la TIR...' y notificaciones 'No tenés permisos para realizar esta acción'.

Posibles causas

ALTA
Permisos insuficientes para el usuario de test
El error 'expected 403 to equal 200' y los mensajes de UI 'No tenés permisos' y 'Missing permissions' en los Toastify, junto con los 403 en el HAR, son evidencia directa de un problema de autorización.
MEDIA
Configuración incorrecta de roles/permisos en Auth0
Si los permisos del usuario son correctos, la configuración del rol asignado o del endpoint en Auth0 para el ambiente de producción de Brasil podría ser errónea.
BAJA
Endpoint `/internal-rate-of-return-valuation` mal configurado
Es menos probable que sea un error de configuración del endpoint en sí, dado que el error es 403 (autorización) y no 404 (no encontrado) o 5xx (server error).

Pasos de Troubleshooting

1 Reproducir el spec fallido en un ambiente de staging: TARGET_ENV=staging TARGET_CLIENT=br-gs64 MODE=only SPEC=gs64_smoke_herramientas npm run test
2 Verificar los roles y permisos asignados al usuario 'cy_smoke@mercapsoftware.com' en Auth0 para el ambiente de producción de Brasil.
3 Consultar con el equipo de backend si ha habido cambios recientes en los permisos del endpoint `/internal-rate-of-return-valuation`.
4 Intentar invocar el endpoint `/internal-rate-of-return-valuation` directamente con curl o Postman, usando un token de un usuario con permisos conocidos, para aislar el problema.
