El test 'Mostrar todos los elementos de Cotizaciones de Unidades Indexadas' estaba en ejecución. Falló al intentar encontrar el elemento 'label[for="filter-resource"]', agotando el 'defaultCommandTimeout' de 60000ms. La evidencia del DOM al momento del fallo confirma que el selector buscado no está presente en la estructura HTML, aunque sí existe un elemento similar 'label[for="filter-quoted"]'. La duración total del test fue de 123193ms, lo que indica que el test pudo haber avanzado en otros pasos antes de este timeout específico.

Posibles causas

ALTA
Cambio en la UI del filtro de recursos
El DOM muestra un 'label' con 'for="filter-quoted"' en lugar del esperado 'for="filter-resource"', lo que sugiere que el atributo 'for' del filtro de unidad indexada ha sido modificado en la interfaz de usuario.
ALTA
Selector incorrecto en el test
El test está utilizando un selector obsoleto o incorrecto ('label[for="filter-resource"]') que no se corresponde con el HTML renderizado actualmente ('label[for="filter-quoted"]').
BAJA
Componente de filtro no renderizado
Aunque el elemento específico no se encontró, otros elementos de la página, como los datepickers y la tabla, están presentes en el DOM, lo que hace menos probable un fallo general de renderizado del componente.

3 Reproducir el spec fallido localmente con `TARGET_ENV=production TARGET_CLIENT=br-gs64 MODE=only SPEC=gs64_smoke_cotizaciones npm run test` para observar el comportamiento en tiempo real.
4 Revisar el archivo `cypress/support/commands/cotizaciones.commands.js` en la línea 1379 para identificar el comando exacto que utiliza el selector 'label[for="filter-resource"]'.
