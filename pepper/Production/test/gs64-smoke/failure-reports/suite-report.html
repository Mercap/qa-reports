Timeout de elemento en Cotizaciones de Unidades Indexadas: 'label[for="filter-resource"]' no encontrado.

Descripción detallada

El test 'Mostrar todos los elementos de Cotizaciones de Unidades Indexadas' estaba ejecutando en el ambiente production/br-gs64. Falló al intentar localizar un elemento 'label' con el atributo 'for="filter-resource"'. El comando 'cy.get' agotó su tiempo de espera después de exactamente 60000ms, lo que indica que el elemento no fue encontrado en el DOM. El snapshot del DOM al momento del fallo confirma la ausencia de este selector, aunque otros elementos de la interfaz como los selectores de fecha y un filtro para 'Unidad indexada' están presentes.

Posibles causas

ALTA
Cambio en la UI o selector del filtro.
El DOM muestra un elemento '<label for="filter-quoted">' que es similar en función, lo que sugiere que el selector esperado 'label[for="filter-resource"]' pudo haber sido renombrado o reemplazado en un despliegue reciente.
MEDIA
Componente de filtro no renderizado.
Aunque la página principal cargó, el componente específico que debería contener el 'label[for="filter-resource"]' podría no haberse inicializado o renderizado correctamente debido a un error de JavaScript o datos faltantes.
BAJA
Problema de carga de datos.
Si el filtro depende de datos cargados asincrónicamente, un fallo en la API subyacente podría impedir su renderizado. Sin embargo, no hay evidencia directa de errores de red (4xx/5xx) en los datos proporcionados.

3 Comparar el selector 'label[for="filter-resource"]' con el DOM actual de la página para identificar si hubo un cambio en el atributo 'for' o en el elemento.
4 Revisar el video del fallo para observar el comportamiento de la UI antes del timeout y detectar posibles spinners o errores visuales.
5 Verificar los logs de la aplicación en el ambiente de producción para posibles errores de backend o frontend relacionados con la carga de la página de cotizaciones.
