Fallo de autorización (403) al calcular TIR en Herramientas

Descripción detallada

El test "Herramientas > Calculadora TIR > Descargar el archivo de ejemplo, calcular la TIR y validar el resultado" estaba ejecutando el flujo de cálculo de TIR. El fallo ocurrió al intentar calcular la TIR después de cargar el archivo de ejemplo, cuando el comando de Cypress esperaba un status 200 de la API de cálculo, pero recibió un 403. El HAR muestra dos requests a `/internal-rate-of-return-valuation` que respondieron con 403. La UI de Pepper mostró un mensaje de error "No tenés permisos para realizar esta acción" con el detalle "Missing permissions", confirmando un problema de autorización.

Posibles causas

ALTA
Permisos insuficientes para el usuario GS64
El error 403 de la API y el mensaje "Missing permissions" en la UI son evidencia directa de un problema de autorización para el usuario actual.
MEDIA
Configuración incorrecta de roles/permisos en el ambiente de producción
Podría ser que los permisos del usuario estén bien definidos, pero la configuración del servicio o del ambiente no los esté aplicando correctamente, resultando en un 403.
BAJA
Token de sesión GS64 inválido o expirado
Aunque un 403 puede indicar esto, el mensaje explícito "Missing permissions" sugiere un problema de autorización más específico que una sesión completamente inválida.

Pasos de Troubleshooting

1 Reproducir el spec fallido en `staging` con el mismo usuario GS64 para verificar si el problema es específico de `production`.
2 Verificar los roles y permisos asignados al usuario `cy_smoke@mercapsoftware.com` (o el usuario GS64 configurado para el test) en el sistema de gestión de usuarios de Pepper para el ambiente de Brasil.
3 Consultar con el equipo de backend si hubo cambios recientes en los permisos requeridos para la API `/internal-rate-of-return-valuation`.
4 Intentar realizar la misma operación manualmente en la UI de Pepper en `production` con el usuario de test para confirmar el comportamiento.
5 Si el problema persiste, revisar los logs del servicio `internal-rate-of-return-valuation` para obtener más detalles sobre el error 403.
