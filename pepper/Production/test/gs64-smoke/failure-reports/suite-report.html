Descripción detallada

El test "Mostrar todos los elementos de Cotizaciones de Indices Financieros" estaba ejecutando, buscando verificar la presencia de elementos de UI en la página de "Cotizaciones de Índices Financieros". Posibles causas

ALTA
Selector incorrecto para la página actual
El DOM al momento del fallo no contiene `label[for="filter-resource"]`. El test está en la página "Cotizaciones de Índices Financieros", que tiene filtros diferentes (ej. "Índice financiero").
MEDIA
Cambio de UI en el módulo de Cotizaciones de Índices Financieros
El elemento `label[for="filter-resource"]` podría haber sido removido o renombrado en un deploy reciente, lo que explica su ausencia en el DOM.
BAJA
Componente de filtro no renderizado
Aunque la página parece cargada, podría haber un error de JavaScript que impida la renderización de este filtro específico. Sin embargo, no hay errores JS visibles en el stack o HAR.
