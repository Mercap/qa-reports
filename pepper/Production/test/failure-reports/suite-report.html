Fallo de login Auth0: la UI alterna entre el formulario de login y una página de error 'Oops, something went wrong'.

Descripción detallada

El test 'Ingresar y hacer login' intentó realizar un inicio de sesión. Después de navegar a la URL de Auth0, la interfaz de usuario mostró repetidamente el formulario de login seguido de una página de error genérica 'Oops, something went wrong'. El comando de utilidad personalizado detectó que la UI no se renderizó correctamente después de varios intentos, lo que provocó el fallo del test. La duración del test fue de 8841ms, indicando un fallo rápido por inestabilidad de la UI.

Posibles causas

ALTA
Error de configuración de Auth0
La aparición de la página 'Oops, something went wrong' es un indicador fuerte de un problema interno en Auth0 o en su integración con Mercap Admin para el ambiente de producción.
ALTA
Mala configuración del ambiente/test
El test se ejecuta en 'production/arg-gs32' pero la evidencia (URL y DOM) apunta a un flujo de Auth0 (GS64). Esta discrepancia podría causar un comportamiento inesperado o una configuración incorrecta del tenant de Auth0.
MEDIA
Problema de red transitorio
Una interrupción momentánea en la red podría haber impedido que Auth0 cargara recursos esenciales, resultando en la página de error y la inestabilidad de la UI.

1 Verificar los logs de Auth0 para el tenant 'mercap-admin-test.us.auth0.com' en el momento del fallo para identificar errores específicos.

4 Revisar la configuración de las variables de entorno `PEPPER_USER` y `PEPPER_PASSWORD` para el ambiente de producción/Auth0.
5 Confirmar que el test 'gs32_smoke_all' está configurado para usar el método de autenticación correcto (GS32 vs GS64/Auth0) y que no hay redirecciones inesperadas.
