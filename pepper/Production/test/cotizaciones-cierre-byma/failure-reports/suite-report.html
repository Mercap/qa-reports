Login GS32 fallido por 504 Gateway Timeout al cargar la página administrativa

Descripción detallada

El test intentaba realizar el login a la aplicación Pepper en el entorno de producción. El fallo ocurrió en el paso de navegación inicial, cuando el comando `cy.visit()` intentó cargar la URL `https://admin.mercapabbaco.com/administrative`. La evidencia muestra que el servidor respondió con un error `504 Gateway Timeout`, y la página mostró un mensaje de "Sorry, we could not load". La duración del test fue de 61105ms, lo que indica que se agotó el `pageLoadTimeout` de Cypress (60s).

Posibles causas

ALTA
Problema de infraestructura o sobrecarga del servidor
El error 504 Gateway Timeout es un indicador directo de que el servidor no pudo obtener una respuesta de un servidor upstream a tiempo. La duración de 61105ms confirma que la carga de la página excedió el tiempo límite.
MEDIA
Problema de deploy reciente en producción
Un deploy reciente podría haber introducido inestabilidad o problemas de rendimiento en el servidor, causando que no responda a tiempo.
BAJA
Configuración incorrecta del proxy/gateway
Aunque menos probable, una configuración errónea en el proxy o gateway que maneja las solicitudes a `admin.mercapabbaco.com` podría causar timeouts.
