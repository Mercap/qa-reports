Fallo de autenticación GS64: Auth0 devuelve 'invalid_request' durante el login.

Descripción detallada

El test 'Login > Ingresar y hacer login' estaba intentando autenticarse en la aplicación Pepper. El fallo ocurrió durante el proceso de login, específicamente cuando Auth0 devolvió una página de error en lugar de completar la autenticación. El video y el DOM muestran una página de error de Auth0 con el mensaje 'Oops!, something went wrong' y 'invalid_request: ... issue with cookies, since we couldn't find your session', indicando un problema con la sesión de autenticación o las cookies. El comando personalizado de Cypress para verificar el renderizado de la UI falló después de múltiples reintentos porque la interfaz de usuario esperada de la aplicación nunca apareció.

Posibles causas

ALTA
Auth0 'invalid_request' por sesión/cookies
El DOM al momento del fallo y el video muestran explícitamente la página de error de Auth0 con el mensaje 'invalid_request: ... issue with cookies, since we couldn't find your session', lo que indica un problema directo con la gestión de la sesión o las cookies por parte de Auth0.
ALTA
Credenciales de usuario o sesión cacheada inválida
El mensaje de Auth0 sugiere que la sesión no pudo ser encontrada, lo que podría deberse a credenciales incorrectas o a una sesión cacheada por Cypress (`cy.session`) que se volvió inválida o expiró.
MEDIA
Problema de configuración o servicio de Auth0
El mensaje de error de Auth0 también menciona 'misconfiguration in the system or a service outage', lo que podría indicar un problema en la configuración del cliente Auth0 para el ambiente 'mercap-admin-test' o una interrupción temporal del servicio.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente: TARGET_ENV=production TARGET_CLIENT=arg-gs32 MODE=only SPEC=cotizaciones_cierre_byma.cy.js npm run test
2 Verificar manualmente el login en 'mercap-admin-test.us.auth0.com' con las credenciales de PEPPER_USER/PASSWORD para el ambiente 'arg-gs32'.
3 Revisar los logs de Auth0 para el tenant 'mercap-admin-test' en busca de eventos de 'invalid_request' o fallos de login.
4 Limpiar la caché de Cypress (`cypress cache clear`) y reintentar el test para descartar problemas de sesión cacheada.
5 Verificar la configuración de las credenciales de PEPPER_USER/PASSWORD en el archivo .env para el ambiente 'arg-gs32'.
