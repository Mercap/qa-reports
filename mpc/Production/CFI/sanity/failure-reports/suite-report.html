Descripción detallada

El test "Ingresar y hacer login en el admin de MPC" falló durante el comando `cy.visit` a `https://cfi.mercapportfolio.com/mercapportfolio-admin`. La página, que redirige a un flujo de autenticación de Auth0, no disparó su evento `load` dentro del `pageLoadTimeout` configurado de 120000ms. El HAR no reporta requests fallidos o lentos, pero el DOM al momento del fallo es mínimo, sugiriendo que la página se estancó en una etapa temprana de carga o en una pantalla de error/carga de Auth0.

Posibles causas

ALTA
Auth0 no responde o carga lento
La página de Auth0 no se cargó completamente en 120 segundos, como indica el error 'Timed out after waiting 120000ms for your remote page to load'. El DOM mínimo y la ausencia de errores de red directos en el HAR sugieren que la página se quedó 'colgada' antes de cargar todos sus recursos.
MEDIA
Recursos de Auth0 bloqueados/fallidos
Aunque el HAR no reporta fallos explícitos, es posible que scripts o stylesheets críticos de Auth0 no se hayan descargado o ejecutado correctamente, impidiendo el evento `load` y causando el timeout. El error menciona que 'Browsers will not fire the `load` event until all stylesheets and scripts are done downloading'.
MEDIA
Problema de infraestructura en `production/cfi`
Un `pageLoadTimeout` de 120 segundos en un entorno de producción, especialmente en un paso crítico de login, podría indicar un problema más amplio de disponibilidad o rendimiento del servidor que aloja Auth0 o la aplicación MPC para el cliente CFI.

Pasos de Troubleshooting

1 Verificar manualmente la URL `https://cfi.mercapportfolio.com/mercapportfolio-admin` en el navegador para observar el comportamiento de carga y si Auth0 se muestra correctamente.
2 Reproducir el spec localmente: `TARGET_ENV=production TARGET_CLIENT=cfi MODE=only SPEC=sanity.cy.js npm run metrics-x-spec`.
3 Revisar la consola del navegador durante la carga manual para identificar errores de red o JavaScript en la página de Auth0.
4 Consultar el estado de los servicios de Auth0 y la infraestructura de MPC para el ambiente `production/cfi`.
5 Considerar aumentar temporalmente el `pageLoadTimeout` en `cypress.config.js` para ver si la página eventualmente carga, lo que indicaría un problema de rendimiento.
