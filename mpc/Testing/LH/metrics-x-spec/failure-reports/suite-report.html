Posibles causas

ALTA
URL incorrecta o desactualizada en el test
El `cy.visit()` intentó acceder a una URL que el servidor respondió con un 404, como se ve en el error de Cypress y el screenshot. Esto sugiere que la ruta configurada en el test no es la correcta o ha cambiado.
ALTA
Problema de despliegue o configuración del ambiente
El endpoint `/mercap-portfolio-admin` podría no estar desplegado correctamente o la configuración de enrutamiento en el ambiente `testing/laholando` es incorrecta, impidiendo que el servidor encuentre el recurso.
MEDIA
Servicio de Mercap Portfolio Admin no disponible
Aunque el 404 indica que el servidor fue alcanzado, el servicio específico para la ruta `/mercap-portfolio-admin` podría estar caído o no iniciado en el ambiente `testing/laholando`.
