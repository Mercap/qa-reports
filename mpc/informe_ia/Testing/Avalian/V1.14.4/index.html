🧩 Hipótesis de causa raíz

Posibles causas para las secciones con degradación >15%.

🔴 Alta — Agenda
Problemas de optimización en consultas a la base de datos para filtros complejos (ej. Bonos, Pendiente, fechas pasadas) en la sección Agenda.
Ineficiencias en el procesamiento de grandes volúmenes de datos o cálculos complejos al cargar la Agenda con filtros específicos. Cambios recientes en la lógica de negocio o APIs que impactan la carga de datos en la Agenda, especialmente para estados y rangos de fechas.
🟡 Media — Resultado
Aumento en la complejidad de los cálculos de P&L o la cantidad de datos a procesar para la sección Resultado.
Ineficiencias en la agregación o presentación de datos históricos de resultados que se manifiestan con el tiempo. Problemas de rendimiento en los servicios backend que alimentan la sección Resultado, exacerbados por la carga de datos.
🔵 Baja — Mis portfolios
Aumento en la cantidad de portfolios o la complejidad de los datos asociados a cada uno, afectando la carga inicial.
Consultas ineficientes al listar o detallar portfolios, especialmente si se introdujeron nuevos campos o relaciones.
🔵 Baja — Rendimiento
Ineficiencias en la generación de gráficos o cálculos de rendimiento para ciertos rangos de tiempo o métodos.
Aumento en la cantidad de datos históricos necesarios para calcular el rendimiento, impactando la carga inicial de las cartas.
