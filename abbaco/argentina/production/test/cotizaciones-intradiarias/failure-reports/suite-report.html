Descripción detallada

El test 'Validar la cotización intradiaria del bono AL30 sea la correcta' falló al intentar interactuar con el buscador de especies en el módulo de Sensibilidad. Cypress detectó que el input '#sensitivity-security-search' no es visible porque está cubierto por un elemento de texto perteneciente al popover de novedades ('Actualización de precios'). El fallo ocurrió tras agotar el defaultCommandTimeout de 90000ms, confirmando que el bloqueo fue persistente durante toda la ejecución del paso.

Posibles causas

ALTA
Bloqueo por popover de Changelog
El error de Cypress indica explícitamente que el input está cubierto por el elemento '<p>Desde e...</p>', el cual coincide con el contenido del anuncio de precios visible en el screenshot y el DOM (#changelog-preview-bubble).
MEDIA
Z-index o posicionamiento incorrecto
El popover de novedades tiene un posicionamiento que colisiona con los elementos interactivos de los modales/offcanvas laterales, impidiendo el flujo normal del test.

Pasos de Troubleshooting

1 Reproducir el fallo localmente: TARGET_ENV=production SPEC=cotizaciones-intradiarias_02_check-intraday-quotes-abbaco.cy.js npm run test
2 Verificar en el video si el popover aparece inmediatamente después de abrir el módulo de Sensibilidad.
3 Inspeccionar el LocalStorage para identificar la clave que controla la visualización del changelog y forzar su cierre en el setup del test.
4 Probar el uso de {force: true} en el comando cy.get('#sensitivity-security-search').type(...) como workaround temporal.
5 Validar si el popover puede cerrarse haciendo click en '.btn-close' dentro de '#changelog-preview-bubble' antes de proceder con la búsqueda.
