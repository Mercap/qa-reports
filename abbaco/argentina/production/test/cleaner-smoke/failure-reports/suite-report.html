Error 404 en API de precio para AL30 — el bono se muestra sin cotización (guion) en el portafolio

Descripción detallada

El flujo de validación de valorización del portafolio falló al no encontrar un precio numérico para el bono AL30. Durante los 90s de reintentos, la celda de precio mostró un guion '-', lo que disparó el fallo de la regex. La evidencia del HAR muestra que la consulta al endpoint /single-date-price para la fecha 2026-10-29 devolvió un error 404. Además, el DOM y la UI muestran un cartel de advertencia confirmando la falta de precios actualizados para instrumentos en el portafolio.

Posibles causas

ALTA
Falta de datos en API de mercado
El HAR registra un status 404 en la request a /single-date-price para el ID de AL30, indicando que la cotización no está disponible para esa fecha específica.
MEDIA
Bono sin precio de cierre
El mensaje de alerta en la UI 'No existe un precio actualizado de 1 de tus Instrumento(s)' sugiere que el sistema detectó la falta de datos de cierre para el bono.
