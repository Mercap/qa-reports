Descripción detallada

El test falló al intentar validar la pestaña 'General' del emisor Vista Energy Argentina S.A.U. Específicamente, Cypress no pudo encontrar el elemento del gráfico Highcharts ('rect.highcharts-background') dentro del card 'Cronograma de Pagos' tras 90 segundos de reintentos. La evidencia del DOM y el screenshot confirman que el componente falló al cargar, mostrando el mensaje de alerta: 'No pudimos cargar el cronograma de pagos. Probá de nuevo.'

Posibles causas

ALTA
Error de API en endpoint de cronograma
El DOM muestra un alert de error explícito dentro del card de Cronograma de Pagos, lo que indica que la petición al BFF o a la API de Mercap falló o devolvió datos inválidos.
MEDIA
Timeout de respuesta del backend
Si el endpoint /upcoming-payments tardó más de lo que el componente frontend tolera, este muestra el mensaje de error por defecto, bloqueando la aparición del selector Highcharts.
BAJA
Datos inexistentes para el emisor
El emisor Vista Energy podría no tener datos de vencimientos cargados en producción, y el frontend maneja la respuesta vacía como un error de carga.

1 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=smoke/emisores.js npm run test

3 Inspeccionar el HAR completo para identificar el status code del endpoint: /bff/issuers/01a0c65f-5640-76bd-d3ca8da3b9e6/upcoming-payments
4 Validar la respuesta de la API con curl: curl -X GET 'https://api.mercapabbaco.com/bff/issuers/01a0c65f-5640-76bd-d3ca8da3b9e6/upcoming-payments?months=12&limit=10&offset=0'
5 Revisar logs de Sentry o Datadog buscando errores 5xx asociados al servicio de emisores.
