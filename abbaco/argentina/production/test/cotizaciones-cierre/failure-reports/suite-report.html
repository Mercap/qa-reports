Descripción detallada

Durante la ejecución del flujo para agregar bonos en 'Mis Portafolios', el test falló al intentar interactuar con el input '#bond-searchbar'. Cypress reportó que el elemento no es visible porque está cubierto por un componente de anuncio (#changelog-preview-bubble) que contiene el texto 'Desde el 1/11...'. El test agotó el timeout de 90 segundos esperando que el input quedara descubierto para proceder con la carga de los bonos MR43O, BDC28 y TX28.

Posibles causas

ALTA
Superposición de UI por Popover de Anuncios
El error de Cypress identifica explícitamente el párrafo del anuncio como el elemento bloqueador. El DOM de fallo confirma que el popover está activo y posicionado sobre el área del buscador.
BAJA
Regresión en el z-index del Offcanvas
Un cambio reciente en los estilos de Bootstrap o del layout podría haber provocado que los modales/offcanvas queden por debajo de las capas de notificación globales.

1 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=cotizaciones-cierre_02_check-closing-quotes-abbaco-arg.cy.js npx cypress run
2 Verificar si el popover de anuncios aparece de forma consistente o si depende de cookies/localStorage (ej. 'changelog-viewed').
3 Inspeccionar el z-index de '.offcanvas' vs '.popover' en las herramientas de desarrollador del navegador.
4 Validar si el anuncio se puede cerrar mediante un click en el botón 'btn-close' presente en el DOM de fallo.
5 Implementar un comando de limpieza 'cy.closeAnnouncements()' en cypress/support/commands.js para asegurar una UI limpia antes de interactuar con formularios.
