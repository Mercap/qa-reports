Descripción detallada

El test 'Validaciones en la pestaña General de la especie TX28' falló al ejecutar una aserción sobre la tabla de Métricas Secundarias. Se esperaba que los valores no fueran 'N/A', pero se encontró la cadena concatenada 'N/AN/AN/AN/AN/A'. La duración extremadamente corta (1628ms) y la ausencia de errores 4xx/5xx en el HAR indican que la API respondió correctamente, pero entregó valores nulos o vacíos que el frontend renderizó por defecto.

Posibles causas

ALTA
Datos faltantes en la respuesta de la API
El HAR muestra que las peticiones de red finalizaron con éxito, pero la UI muestra 'N/A' en todos los campos de la tabla de métricas, lo cual es el comportamiento estándar ante valores null en el JSON de respuesta.
MEDIA
Error de carga parcial de la especie
El screenshot muestra que mientras la tabla de métricas ya renderizó 'N/A', la sección de 'Gráficos Históricos' aún muestra un placeholder de carga (glow), sugiriendo una carga incompleta de los datos de la especie.

Pasos de Troubleshooting

1 Verificar manualmente la especie TX28 en https://bonds.mercapabbaco.com/bond-analysis/BYMA/TX28 para confirmar si el error es persistente.
2 Inspeccionar en el HAR el response body del endpoint de métricas (ej: /tradable-securities/.../metrics) para validar si los campos vienen nulos.
3 Ejecutar el spec de forma aislada en local: TARGET_ENV=production TARGET_CLIENT=argentina npx cypress run --spec '**/analizar.cy.js' --browser firefox
4 Comparar la respuesta de la API para TX28 contra otra especie similar (ej: TX26) para descartar un problema general del servicio de métricas.
