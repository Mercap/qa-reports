Descripción detallada

El test falló durante el flujo de adición de activos al portafolio (especies AL30, MR43O, etc.). A pesar de que la evidencia visual (screenshot) muestra el modal 'Nuevo bono' abierto y con un campo de búsqueda visible, Cypress no logró localizar el elemento con el ID '#bond-searchbar' tras agotar el timeout de 90 segundos. El DOM-FALLO revela que el componente de búsqueda utiliza el ID '#bond-search' en su contenedor, pero el input interno no posee el ID esperado por el test, lo que indica una desincronización entre el código del test y la UI actual.

Posibles causas

ALTA
Renombramiento de ID en el componente Searchbar
El DOM-FALLO muestra un contenedor con ID '#bond-search' y un input sin ID específico. Es altamente probable que una actualización reciente de la UI haya eliminado o cambiado el ID '#bond-searchbar' que el test intenta utilizar.
MEDIA
Interferencia del popover de Changelog
El screenshot muestra el popover 'Actualización de precios' superpuesto al modal. Aunque el error es de 'no encontrado' y no de 'cubierto', la presencia de este elemento disruptivo podría haber causado un cierre inesperado del modal o interferido con el renderizado correcto de los elementos internos en el DOM capturado.
BAJA
Fallo en la apertura completa del modal
Si el modal no se renderizó completamente en el árbol del DOM (aunque sea visible en el buffer de video/screenshot), Cypress no podrá interactuar con sus hijos. El DOM-FALLO no muestra las clases típicas de modal de Bootstrap ('modal-open' o 'modal-backdrop').

Pasos de Troubleshooting

1 Ejecutar el test localmente para inspeccionar el DOM en vivo: SPEC=sanity_portafolio npm run cy:open
2 Verificar en el navegador si el input de búsqueda dentro del modal 'Agregar bono' posee el ID '#bond-searchbar' o si fue reemplazado por una clase.
3 Validar si el comando custom en 'cypress/support/commands.js:837' está apuntando al selector correcto para el ambiente de producción.
4 Comprobar si el popover de 'Actualización de precios' aparece consistentemente y si su cierre manual permite que el test encuentre el elemento.
5 Actualizar el Page Object o comando custom para usar un selector más robusto como '#bond-search input' o un atributo data-cy.
