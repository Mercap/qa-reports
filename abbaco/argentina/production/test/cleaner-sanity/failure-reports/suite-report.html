Descripción detallada

El test falló al intentar interactuar con el buscador de bonos. Cypress localizó el input `#bond-searchbar`, pero este se desprendió del DOM (detached) antes de que la acción pudiera completarse. La duración del test (181s) y el timeout de 90s indican que Cypress esperó estabilidad sin éxito. El DOM de fallo muestra un popover de 'Actualización de precios' (changelog) activo y un modal lateral de 'Nuevo bono' abierto, elementos que provocan re-renders asincrónicos en el layout superior de React.

Posibles causas

ALTA
Interferencia del popover de Changelog
El DOM muestra el elemento `changelog-preview-bubble` con la clase `show`. Su renderizado asincrónico suele desmontar y volver a montar componentes hermanos en el header, invalidando las referencias de Cypress.
MEDIA
Re-render por apertura de modal lateral
La apertura del panel 'Nuevo bono' (visible en screenshot) puede disparar un cambio de estado global que refresca el buscador del top-bar.
BAJA
Race condition en el hook de búsqueda
El componente `Searchbar-CEse2lp6.js` podría estar re-renderizándose al inicializar el contexto de búsqueda del portafolio.

Pasos de Troubleshooting

1 Reproducir localmente: `TARGET_ENV=production TARGET_CLIENT=argentina SPEC=sanity_portafolio npm run test`
2 Verificar en el video si el popover de precios aparece exactamente en el momento del click fallido
3 Intentar cerrar el popover de novedades programáticamente antes de interactuar con el buscador
4 Refactorizar el comando para evitar el encadenamiento largo: `cy.get('#bond-searchbar').as('search'); cy.get('@search').type('...')`
5 Validar si el selector `#bond-searchbar` es el correcto para el modal lateral o si existe una colisión con el buscador global
