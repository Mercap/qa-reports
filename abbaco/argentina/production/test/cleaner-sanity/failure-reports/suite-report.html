Descripción detallada

El test ejecutaba la validación de presencia de curvas en la pestaña *Todas* de Argentina (sanity_curvas.cy.js). El fallo ocurrió tras 90 segundos de reintentos en una aserción personalizada que comparaba un listado esperado contra los elementos visibles en la UI. Se identificaron 8 curvas faltantes, todas pertenecientes al sector *Corporativos* y mayormente bajo la modalidad *Tasa Flotante*. El DOM muestra que la página cargó correctamente y otras curvas similares (en USD) están presentes, lo que indica que la aplicación es funcional pero los datos no coinciden con la expectativa del test.

Posibles causas

ALTA
Cambio en la oferta de datos de la API de Mercap
La API no está retornando las curvas específicas de Tasa Flotante para los sectores listados (ej. Petróleo, Gas y Combustibles). El DOM del fallo confirma que existen las versiones en USD para esos mismos sectores, pero no las de Tasa Flotante.
MEDIA
Fixture de test desactualizado
El test utiliza una lista estática de curvas esperadas que no refleja cambios recientes en el mercado o en la configuración de Abbaco para el ambiente de producción.

Pasos de Troubleshooting

1 Verificar manualmente en bonds.mercapabbaco.com/curves si las curvas de Tasa Flotante mencionadas aparecen en la pestaña Todas.
2 Ejecutar el test localmente apuntando a producción para confirmar persistencia: SPEC=sanity_curvas.cy.js npm run test
3 Revisar en el HAR la respuesta del endpoint de listado de curvas para confirmar si la API de Mercap las está enviando en el JSON.
4 Comparar el listado de curvas esperado en el archivo de soporte (commands.js:560) contra la respuesta real de la API.
