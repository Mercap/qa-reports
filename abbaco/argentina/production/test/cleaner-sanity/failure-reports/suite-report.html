Descripción detallada

El test 'Validar que se muestren todas las curvas esperadas' falló al no encontrar un elemento específico en el listado. Aunque el elemento existe en el DOM-FALLO, la duración total de 1179ms es extremadamente baja para una carga completa de datos. El uso de un bloque '.then()' en 'commands.js:530' indica una validación imperativa que no reintenta, capturando la lista antes de que la API de Mercap terminara de renderizar todos los items.

Posibles causas

ALTA
Sincronización (Race Condition)
La validación se ejecuta mediante un '.then()' que no tiene lógica de reintento incorporada. Con una duración de 1.1s y solo 1 request registrado en el HAR, es evidente que Cypress evaluó la lista antes de que todos los elementos fueran inyectados en el DOM.
BAJA
Mismatch de texto invisible
Diferencia sutil en el string (espacios extra o caracteres especiales) entre el fixture de 'curvas esperadas' y el texto renderizado en el componente 'CurvesListItem'.
