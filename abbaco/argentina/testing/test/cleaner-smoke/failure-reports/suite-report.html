Descripción detallada

El flujo de login se detuvo en la pantalla de Auth0. El screenshot muestra explícitamente el mensaje 'Wrong email or password', lo que impidió la redirección esperada a la aplicación. El error de Cypress (origin mismatch) ocurre porque el test intenta ejecutar una aserción de URL y un hook 'after each' esperando el dominio 'bonds.testing.mercap.com.ar', pero el navegador permanece bloqueado en el dominio de Auth0. Posibles causas

ALTA
Credenciales incorrectas
El screenshot captura la UI de Auth0 con el mensaje de error 'Wrong email or password' después de que el test ingresara 'Testing1.' como contraseña.
ALTA
Falla de infraestructura (DNS)
El HAR registra 5 peticiones fallidas a api.testing.mercap.com.ar con status 530. El body indica 'Error 1016: Origin DNS error', lo que sugiere que el ambiente de testing está caído o mal configurado en Cloudflare.
MEDIA
Falta de bloque cy.origin
Cypress detecta un cambio de origen no manejado. Si el flujo requiere interactuar con Auth0 manualmente (sin cy.session), los comandos deben estar envueltos en cy.origin('https://mercap-testing.us.auth0.com', ...).

2 Validar las credenciales del usuario cysmokeabbaco1@gmail.com directamente en el portal de Auth0 o la web de testing.
3 Ejecutar el spec de forma aislada: TARGET_ENV=testing TARGET_CLIENT=argentina MODE=only SPEC=smoke_01_login.cy.js npm run test
4 Revisar si el secreto de la contraseña en el CI/CD coincide con 'Testing1.' o si fue rotado recientemente.
