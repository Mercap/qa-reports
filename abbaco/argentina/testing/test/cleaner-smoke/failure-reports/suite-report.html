Descripción detallada

El test 'Login Abbaco' falló al intentar validar que la URL final coincidiera con el dominio de la aplicación tras el inicio de sesión. La evidencia visual muestra el mensaje 'Wrong email or password' en la interfaz de Auth0, lo que impidió la redirección. El HAR revela una falla crítica de infraestructura con múltiples errores 530 (Origin DNS error) en 'api.testing.mercap.com.ar', indicando que el backend de testing es inalcanzable.

Posibles causas

ALTA
Credenciales de humo inválidas
La captura de pantalla muestra explícitamente el error 'Wrong email or password' para el usuario cysmokeabbaco1@gmail.com.
ALTA
Caída de infraestructura DNS (Cloudflare 1016)
El HAR registra 8 fallos con status 530 y el mensaje 'Cloudflare is unable to resolve the origin DNS for this domain' para la API de testing.
MEDIA
Manejo de origen cruzado en Cypress
El error técnico indica que Cypress intentó ejecutar comandos en un dominio inesperado (Auth0) porque la redirección al dominio principal nunca ocurrió.

Pasos de Troubleshooting

1 Verificar conectividad de la API: curl -I https://api.testing.mercap.com.ar/subscription-plans/
2 Validar manualmente las credenciales del usuario cysmokeabbaco1@gmail.com en el ambiente de testing.
3 Reproducir el fallo localmente: TARGET_ENV=testing TARGET_CLIENT=argentina SPEC=smoke/01_login.cy.js npm run test
4 Revisar la configuración de DNS/CNAME en el dashboard de Cloudflare para el dominio api.testing.mercap.com.ar.
5 Verificar si hubo un cambio reciente en el flujo de Auth0 que requiera el uso de cy.origin() de forma explícita.
