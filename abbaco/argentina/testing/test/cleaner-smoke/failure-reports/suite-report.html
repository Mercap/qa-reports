Fallo de login por credenciales inválidas en Auth0 y error de infraestructura 530 (DNS) en API de Mercap

Descripción detallada

El test 'Login Abbaco' falló al intentar validar la redirección post-autenticación. La UI de Auth0 muestra explícitamente 'Wrong email or password' tras ingresar las credenciales (cysmokeabbaco1@gmail.com / Testing1.). Simultáneamente, el HAR revela múltiples errores 530 (Origin DNS error) en la API de testing, indicando que Cloudflare no puede resolver el origen. El error de Cypress (cross-origin) ocurre porque el test intenta ejecutar comandos esperando el dominio de Abbaco mientras el navegador sigue atrapado en Auth0 debido al fallo de login.

Posibles causas

ALTA
Credenciales incorrectas
La captura de pantalla muestra el mensaje de error 'Wrong email or password' en el formulario de Auth0 tras el intento de login.
ALTA
Fallo de infraestructura DNS (Error 530)
El HAR registra 8 fallos con status 530 y el mensaje 'Cloudflare is unable to resolve the origin DNS' para el dominio api.testing.mercap.com.ar.
BAJA
Manejo de origen cruzado (cy.origin)
Cypress detecta un cambio de origen no manejado, aunque esto es una consecuencia de que el login falló y no redirigió al dominio principal.

Pasos de Troubleshooting

1 Verificar el estado de los registros DNS en Cloudflare para api.testing.mercap.com.ar.
2 Validar manualmente las credenciales cysmokeabbaco1@gmail.com en https://mercap-testing.us.auth0.com.
3 Ejecutar el test de forma local para descartar problemas de red temporales: TARGET_ENV=testing SPEC=cypress/e2e/01_login.cy.js npx cypress run
4 Comprobar si el servicio de backend en el ambiente de testing está activo y respondiendo a peticiones directas vía curl.
5 Revisar si hubo cambios recientes en el password del usuario de smoke test en el dashboard de Auth0.
