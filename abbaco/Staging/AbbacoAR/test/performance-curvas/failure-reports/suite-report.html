Descripción detallada

El test falló durante el flujo de ingreso a la curva soberana de Brasil al intentar validar que los elementos de carga desaparecieran. Según el screenshot y el DOM, el gráfico de Highcharts se renderizó correctamente con sus 21 series, pero la tabla lateral permaneció bloqueada con elementos 'span.placeholder-glow'. La duración total de 125s indica que Cypress agotó el timeout de 120s definido en la aserción sin que la UI transicionara al estado de datos.

Posibles causas

ALTA
Bug de UI: Dependencia de carga bloqueante
El componente de tabla podría estar esperando la resolución de la petición a '/user-profiles/.../favorites/yieldCurve' para ocultar sus placeholders. Al recibir un 404 constante, el estado de carga nunca se limpia.
MEDIA
Fallo en la API de desglose de bonos
Aunque el gráfico cargó, la petición específica que puebla la tabla de la derecha podría haber fallado silenciosamente o no haber sido gatillada, manteniendo el 'aria-label=Cargando datos de la tabla'.
BAJA
Inconsistencia de perfil en Staging
El error 404 indica que el perfil de usuario 'c0b6d4d8...' no existe en el ambiente de staging, lo que podría estar rompiendo la lógica de renderizado de componentes personalizados.
