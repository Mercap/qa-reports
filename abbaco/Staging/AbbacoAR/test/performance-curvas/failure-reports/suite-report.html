Descripción detallada

El test falló en el hook 'before all' durante la creación de la sesión con cy.SessionAbbaco(). Cypress esperó 90000ms por el elemento '.ball-loader' (spinner de carga) que nunca fue detectado. La captura de pantalla muestra que la aplicación ya alcanzó el dashboard 'Inicio', pero con múltiples errores 404 en la consola para el endpoint de favoritos de curvas, lo que sugiere que una falla en la carga de datos inicial pudo haber alterado el flujo de renderizado del loader esperado en commands.js.

Posibles causas

ALTA
Falla en API de perfiles de usuario
La consola muestra múltiples errores 404 en 'api.staging.mercap.com.ar/.../favorites/yieldCurve'. Si el script de login espera el loader mientras se resuelven estas peticiones, el fallo inmediato de red podría saltar el estado de carga.
MEDIA
Race condition en el comando de login
La aplicación en staging cargó el dashboard más rápido de lo que Cypress pudo detectar la aparición del '.ball-loader', resultando en un timeout de espera por un elemento que ya desapareció.
BAJA
Cambio de UI en v1.45.3
El componente '.ball-loader' podría haber sido reemplazado o renombrado en la versión actual de la plataforma, aunque el DOM-baseline lo muestra presente.
