Descripción detallada

El test 'Agregar la primera especie al portafolio' falló al intentar validar el precio del bono AL30 en la tabla de posición. La ejecución se detuvo tras 90000ms (timeout de Cypress) porque el valor encontrado en la celda de precio fue '-' en lugar de un número. El HAR revela que la request a /single-date-price devolvió un error 404 indicando explícitamente la falta de cotización para la fecha 2026-11-17, lo cual es confirmado por el cartel de advertencia visible en la UI.

Posibles causas

ALTA
Falta de datos en la API de Mercap (404 Not Found)
El endpoint /single-date-price respondió con status 404 y el mensaje 'No hay precio para... al 17 November 2026'. Esto se refleja en la UI con un guion en la columna Precio y un alert de sistema sobre instrumentos sin precio actualizado.
MEDIA
Configuración de fecha futura en el ambiente
La request solicita precios para el año 2026. Si el ambiente no está configurado para simular datos futuros o si la fecha es incorrecta por un problema de infraestructura, la API fallará por falta de registros históricos/proyectados.
