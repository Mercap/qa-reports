Posibles causas

ALTA

El endpoint /single-date-price devolvió un status 404 con el mensaje 'No hay precio para... al 29 October 2026', lo que impacta directamente en la UI mostrando un guion.

Desincronización en el esquema de valuación
El parámetro valuationScheme enviado en la request podría no tener datos procesados para este instrumento específico en el ambiente de producción.
