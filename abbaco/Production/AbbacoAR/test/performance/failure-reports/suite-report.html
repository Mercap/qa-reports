Fallo en precio de AL30 en Portafolio — API devolvió 404 y la UI mostró '-' invalidando la aserción numérica.

Descripción detallada

El test ejecutaba el flujo de agregar el bono AL30 al portafolio y validar su correcta visualización en la tabla de posición. El fallo ocurrió en la aserción del precio, que recibió un guion '-' en lugar de un valor numérico, agotando los 90s de reintento. El HAR confirma que la request al endpoint /single-date-price falló con un error 404 explícito: 'No hay precio para AL30 al 16 November 2026'.

Posibles causas

ALTA
Falta de datos en API de Mercap
El HAR muestra un status 404 en /single-date-price con el mensaje 'No hay precio para...'. Esto impacta directamente en la UI que muestra un guion en la columna Precio.
MEDIA
Rigidez en la aserción del test
El test espera que siempre haya un precio numérico (match /\d/), pero el sistema está diseñado para mostrar '-' (guion) y un cartel de advertencia cuando el dato no existe, lo cual es un comportamiento válido de la app.

Pasos de Troubleshooting

1 Verificar manualmente en producción si el bono AL30 muestra precio en la sección Mis Portafolios.
2 Validar el endpoint fallido con curl: curl 'https://api.mercapabbaco.com/single-date-price?instrument=https%3A%2F%2Fapi.mercapabbaco.com%2Fbonds%2Fecfe885d-8163-4222-acb1-f7020cf05a4a&date=2026-11-16'
3 Reproducir el fallo localmente: TARGET_ENV=production TARGET_CLIENT=argentina MODE=only SPEC=performance_portafolio npm run test
4 Consultar al equipo de Backend/Datos si hay un delay en la carga de precios de cierre para el 16/11/2026.
