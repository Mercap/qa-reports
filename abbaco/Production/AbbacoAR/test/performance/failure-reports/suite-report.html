Descripción detallada

El test 'Ingresar al menú Calculadora' falló al intentar validar la presencia del título 'Calculadora de Bonos'. Según el screenshot y el DOM-FALLO, la aplicación nunca navegó fuera de la página de Inicio (Dashboard), manteniendo activa la sección 'Inicio' en el sidebar. El test agotó los 90000ms esperando el cambio de contenido. El HAR no muestra errores de red (94 requests exitosas), lo que apunta a un problema de interacción UI o de navegación interna de la SPA que impidió el cambio de ruta.

Posibles causas

ALTA
Interacción de click fallida en el sidebar
El DOM-FALLO muestra que el link a /calculator existe pero la sección activa sigue siendo 'Inicio' (href='/'). El screenshot confirma que el contenido visible es el dashboard de favoritos.
MEDIA
Intercepción del click por elemento UI (Changelog)
El componente de 'Changelog' tiene 4 notificaciones pendientes según el DOM. A veces estos elementos o sus overlays pueden interferir con clicks en el sidebar si no están bien posicionados.

Pasos de Troubleshooting

1 Reproducir localmente: TARGET_ENV=production TARGET_CLIENT=argentina SPEC=performance/calculadora.js npm run cy:open
2 Verificar en el log de Cypress si el comando 'click' sobre el sidebar se marcó como exitoso.
3 Inspeccionar si hay elementos transparentes (overlays) bloqueando el sidebar al inicio de la sesión.
4 Probar el uso de {force: true} en el click del sidebar como medida paliativa.
5 Validar si el cambio a cy.visit('/calculator') resuelve el problema de navegación.
